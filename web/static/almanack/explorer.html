How it counts

The counting follows the rest of the Almanack: a ball faced is any ball that was not a wide; a bowler is charged runs off the bat, wides and no-balls, never byes or leg-byes, and credited only the wickets that are the bowler's own; a batting position is the order in which batters first reached the crease; super overs are left out. An innings is counted for a batter who reached the crease, so a run out without facing a ball is an innings.
