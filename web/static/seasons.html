Nineteen seasons

The Indian Premier League has run for 19 seasons, from 2008 to 2026, and eight different franchises have won it. Chennai Super Kings and Mumbai Indians have won the most titles, 5 each. Each season below has its own page: the final and how it was won, the league table, every knockout match, and the leading run-scorers and wicket-takers, all counted from the same ball-by-ball record the game is built on.

Counting rules

Runs, balls and wickets are counted from Cricsheet's ball-by-ball data. Super overs count for the result only. A ball faced is any ball that was not a wide, so a no-ball counts. A bowler is charged runs off the bat, wides and no-balls, never byes or leg-byes, and is credited only the wickets that are his, so a run out is not. Matches abandoned without a ball being bowled are not in the record. Figures can therefore differ slightly from other sources that count differently.
